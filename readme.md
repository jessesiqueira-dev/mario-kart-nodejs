# 🏎️ Mario Kart Node.js

## 📌 Sobre

Projeto desenvolvido como desafio da DIO, simulando uma corrida inspirada no Mario Kart usando Node.js.

## 🚀 Funcionalidades

* Corrida entre personagens
* Sistema de pontuação
* Ranking final

## 🛠️ Tecnologias

* Node.js
* JavaScript

## ▶️ Como executar

```bash
npm install
npm start
```
